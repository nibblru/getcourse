# GetCourse Video Downloader (тестовая версия)

**Внимание:** Этот проект находится на стадии тестирования. Скрипт пока не является полностью рабочим инструментом и может не справляться с загрузкой всех типов видео с платформы GetCourse.

Цель проекта — исследовать технические возможности работы с потоковым видео и HLS-потоками. Мы не предоставляем готовое решение для массового скачивания курсов и не нарушаем авторские права.
